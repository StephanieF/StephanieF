## 🔭 Lead Project: Local Lore

**A local LLM-driven documentation engine focused on privacy and domain-specific information.**

Local Lore runs the language model on your own machine, so the documents you feed it stay there unless you decide otherwise. The goal is a tool that can generate and search documentation for a specialized domain without sending sensitive material to an outside API.

- **Privacy first:** your content is never sent to an external API unless you choose to connect one
- **Local always:** everything works offline, on local models
- **Domain aware:** tuned to the vocabulary and knowledge of one subject area

**Status:** early stage. The architecture and tech stack are still being settled, and the repository is private until there is something worth running.
